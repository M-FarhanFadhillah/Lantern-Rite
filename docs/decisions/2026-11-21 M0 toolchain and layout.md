# 2026-11-21 M0 toolchain and layout
PRD section: §14 (Stack table, Project layout), §15 (Required and Optional tables, first-day checklist)
Was: Blender 4.x; Blender MCP via `uvx blender-mcp`; Rokit pinning Rojo, Wally, StyLua, Selene and Lune; the §14 layout without spec, preview or plan folders.
Now: What is actually installed and wired up after M0 Part A.

- **Rokit 1.2.0** pins these in `rokit.toml`: Rojo 7.7.1, Wally 0.3.2, StyLua 2.6.0, Selene 0.32.0, Lune 0.11.1, Zap 0.6.29, luau-lsp 1.70.1. The luau-lsp CLI (`luau-lsp analyze`) type-checks `--!strict` code. Its Roblox definitions file is downloaded per version into the git-ignored `.luau-lsp/` folder by `tools/check.ps1`.
- **Wally packages:** React and ReactRoblox 17.2.1 (shared), ProfileStore `lm-loleris/profilestore` 1.0.3 (server), Jest and JestGlobals 3.10.0 (dev). `wally.toml` needs `[place] shared-packages = "game.ReplicatedStorage.Packages"` because Jest depends on shared packages.
- **Rojo mapping** (`default.project.json`): `src/shared` to `ReplicatedStorage.Shared`; `Packages` to `ReplicatedStorage.Packages`; `src/server` to `ServerScriptService.Server`; `src/client` to `StarterPlayer.StarterPlayerScripts.Client`; `ServerPackages`, `DevPackages` and `tests/` to `ServerStorage` (server-only). Stripping dev packages from release builds goes on the M5 launch checklist.
- **Services and controllers** are tables with optional `Init` and `Start` functions. The entry scripts (`init.server.luau`, `init.client.luau`) list them in order. The shared Loader (`src/shared/Modules/Loader.luau`) runs every `Init`, then every `Start`, each `Start` in its own thread. An `Init` error names the module.
- **Layout additions for §14:** `art/blender/specs/<kind>/*.json` (generator specs), `art/blender/previews/` (preview PNGs, committed), `art/audio/` (audio uploads), `studio/` (the user's own folder, kept as is), `docs/plans/` (approved plans), `tools/check.ps1` (StyLua, Selene and luau-lsp in one command), `tools/enable-jest-flag.ps1`.
- **§15 tool facts:** Blender 5.3 (Steam build at `E:\SteamLibrary\steamapps\common\Blender\blender.exe`, not on PATH) replaces "Blender 4.x". The Blender MCP in use is the "MCP for Blender" add-on (it updates with `uvx mcp-for-blender install-addon`), not `uvx blender-mcp`. The Rokit row lists Rojo, Wally, StyLua, Selene, Lune, Zap and luau-lsp, so Lune moves from Optional to installed through Rokit. Figma uses the claude.ai Figma connector (already signed in). Figma's rate-limit page lists Starter plans at about 20 MCP calls a month for tools that read designs (`whoami` and `create_new_file` don't count). That is enough for M0 but too few for UI-heavy milestones.
