# Sessions

One note per Claude Code session, named `YYYY-MM-DD HHmm <topic>.md`. Claude Code creates it at the start and appends as it works, so nothing is lost if usage runs out mid-session. The current state always lives in [[Status]].

```markdown
# YYYY-MM-DD HHmm <topic>
Milestone: M?
Model / effort: 
Goal for this session: 

## Log
- HH:mm — what was done; files changed; result

## Decisions
- (link to [[decisions/README|Decisions]] notes)

## Problems / blockers

## Next step
```
